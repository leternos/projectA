# Abreviaturas do dicionário

Legenda das abreviaturas usadas por Azevedo dentro dos grupos analógicos para
marcar registro, domínio, região de uso ou classe gramatical de uma palavra.

Baseada na página "abreviaturas" da segunda edição Lexikon (p. xii).

## Sinais gráficos usados no livro

- **▲** (seta para cima) — marca um dos grupos de um par antagônico.
- **▼** (seta para baixo) — marca o outro grupo do par.
- Grupos "neutros" não trazem seta.
- **=** — geralmente separa a expressão original de uma glosa em latim ou
  francês (ex.: "sem hesitar = *haud cunctanter*").
- **/** dentro de um substantivo composto — indica variantes de intensidade
  ou nuance (ex.: "realidade gélida/pura/palpável/fria/indiscutível").
- **&** — indica que a mesma forma serve para outra classe gramatical
  (ex.: "tardiamente & adj." = tardiamente, e as demais formas adverbiais
  correspondentes aos adjetivos já listados).
- **Número após termo** — remissão para outro grupo com mais analogias
  (ex.: "viver 359" = ver também grupo 359 Vida).

## Como usar os marcadores ao responder

Quando gerar analogias para o usuário, **marque o registro** entre parênteses
depois da palavra sempre que ele for informativo:

> **regozijo** (culto), **festança** (bras., fam.), **pândega** (pop., desuso)

Isso permite ao usuário decidir instantaneamente se o termo cabe no seu contexto
(um romance sério, um post de blog, uma letra de samba, um artigo acadêmico).
