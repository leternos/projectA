# Entradas verbatim dos grupos 1-135

Texto extraído do PDF da 2ª edição Lexikon do *Dicionário Analógico da Língua
Portuguesa* de Francisco Ferreira dos Santos Azevedo, fornecido pelo usuário.

**Cobertura**: apenas os grupos 1 a 135 (aproximadamente 14% dos 1000 grupos do
livro). Para os grupos 136 a 1000, a skill se apoia no título do grupo
(disponível em `../references/classificacao.md`) e no método (ver
`../references/metodo.md`) para gerar analogias sem o texto verbatim.

**Qualidade**: extração OCR do PDF original — resta ruído (caracteres trocados,
palavras cortadas, marcações de estilo remanescentes tipo `*V.*`, `*Adj.*`).
Cerca de 100 grupos receberam heading `### N. Título` normalizado; os demais
podem ser localizados por busca livre pelo título ou pelo número.

**Como buscar**:
- Grep pelo número do grupo: `grep "\<N\." este-arquivo.md`
- Grep por qualquer palavra em português: as entradas contêm as palavras análogas
  em forma corrida, separadas por vírgula.
- Grep pela abreviatura de classe gramatical dentro do grupo: `*V.*` para verbos,
  `*Adj.*` para adjetivos, `*Adv.*` para advérbios, `FRASES:` para expressões
  idiomáticas.

**Formato dentro de cada grupo** (quando o OCR preservou):
- Nome do grupo abre a entrada
- Substantivos aparecem em primeiro lugar, separados por `;` em subgrupos
- `*V.*` marca o bloco de verbos
- `*Adj.*` marca o bloco de adjetivos
- `*Adv.*` marca o bloco de advérbios
- `FRASES:` marca frases feitas e provérbios
- Cross-references são números soltos: "viver 359" = ver também grupo 359
