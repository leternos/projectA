# projectA
Storminders Project A

## Skills

### `dicionario-analogico`

Skill do Claude Code que replica o *Dicionário Analógico da Língua Portuguesa*
de Francisco Ferreira dos Santos Azevedo (método Roget), para ajudar em
escrita, revisão, tradução, poesia e escolha estilística em português.

Estrutura em `.claude/skills/dicionario-analogico/`:

- `SKILL.md` — ponto de entrada (quando ativar, procedimento)
- `references/metodo.md` — o método analógico em profundidade
- `references/classificacao.md` — árvore completa dos 1000 grupos (6 classes,
  24 divisões)
- `references/abreviaturas.md` — legenda das abreviaturas do dicionário
- `data/entradas-grupos-001-135.md` — texto verbatim das entradas dos grupos
  1 a 135, extraído do PDF fornecido pelo usuário
